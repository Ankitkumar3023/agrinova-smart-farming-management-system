# AGRINOVA - Smart Farming Management System

AGRINOVA is a Smart Farming Management System developed to help farmers manage crops, products, and customer orders digitally.

## Features

* Farmer Registration & Login
* Product Management
* Crop Management
* Order Tracking
* Weather Updates
* Fertilizer Suggestions
* Admin Dashboard

## Technologies Used

* Frontend: HTML, CSS, Bootstrap, JavaScript
* Backend: Django / FastAPI
* Database: MySQL
* Tools: VS Code, GitHub

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/agrinova-smart-farming-management-system.git
cd agrinova-smart-farming-management-system
```

## Run Project

```bash
python manage.py runserver
```
